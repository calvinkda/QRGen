# QRGen
One page hors ligne de génération de QR code unique ou en série

## Utilisation en ligne

Ouvrez le site GitHub Pages dans la descrition de ce dépot

## Utilisation hors ligne

Téléchargez le fichier ``index.html``, ouvrez-le dans votre navigateur.
Aucune installation n'est necessaire.

## Fonctionnalités
- QR code unique
- QR code en série numérotée
- Ajout d'un texte ou d'un logo
- Export PNG et SVG
- Mise en page de badges sur A4
- Traitement des logos dans le navigateur
